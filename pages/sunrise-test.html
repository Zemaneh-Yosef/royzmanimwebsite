The new way needs a horizon with base candidates, which only a server running the base-level change (zemaneh-shamayim PR #18) sends. Without them it falls back to today's default (elevation on in Israel, off abroad), and says so above its column. השיטה החדשה צריכה אופק עם נקודות בסיס, שרק שרת עם שינוי הבסיס (zemaneh-shamayim PR #18) שולח. בלעדיהן היא חוזרת לברירת המחדל של היום (גובה מופעל בארץ, כבוי בחו"ל), וכותבת זאת מעל העמודה שלה.
